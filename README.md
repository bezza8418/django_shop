# Django Shop

Интернет-магазин на Django — учебный проект.

## Технологии
- Python 3.12+
- Django 5.x
- PostgreSQL
- Bootstrap 5
- Pillow (для работы с изображениями)

## Функциональность
### Каталог товаров
- ✅ Главная страница со списком товаров
- ✅ Детальная страница товара (описание, цена, изображение)
- ✅ Пагинация на главной странице (6 товаров на страницу)
- ✅ Форма добавления нового товара (пользовательский ввод)
- ✅ Страница контактов с формой обратной связи

### Администрирование
- ✅ Админ-панель для управления категориями и продуктами
- ✅ PostgreSQL в качестве базы данных
- ✅ Фикстуры для экспорта/импорта данных
- ✅ Кастомная команда `load_test_data` для загрузки тестовых данных

### Блог
- ✅ Список блоговых статей (только опубликованные)
- ✅ Детальная страница статьи со счётчиком просмотров
- ✅ Создание, редактирование и удаление статей (CRUD)
- ✅ Все контроллеры построены на Class-Based Views (CBV)

### Шаблоны
- ✅ Общий базовый шаблон `base.html`
- ✅ Подшаблон главного меню `menu.html`
- ✅ Единый стиль для всех страниц (Bootstrap)

## Запуск проекта

1. Клонировать репозиторий
```bash
git clone https://github.com/bezza8418/django_shop.git
cd django_shop
```
2. Создать и активировать виртуальное окружение
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate
```
3. Установить зависимости
```bash
pip install -r requirements.txt
```
4. Настроить переменные окружения
* Создай файл .env в корне проекта:
```
DB_NAME=django_shop
DB_USER=postgres
DB_PASSWORD=твой_пароль
DB_HOST=localhost
DB_PORT=5432
```
5. Создать базу данных PostgreSQL
```sql
CREATE DATABASE django_shop;
```
6. Применить миграции
```bash
python manage.py migrate
```
7. Создать суперпользователя
```bash
python manage.py createsuperuser
```
8. Загрузить тестовые данные (опционально)
```bash
python manage.py load_test_data
```
9. Запустить сервер
```bash
python manage.py runserver
```

## Дополнительные возможности

### Работа с блогом
Список статей: отображаются только опубликованные записи
Просмотр статьи: автоматически увеличивается счётчик просмотров
Управление: создание, редактирование и удаление через веб-интерфейс

### Добавление товара через сайт
Перейдите на страницу `/add/` и заполните форму. Товар автоматически сохранится в базу данных и появится на главной странице.

### Просмотр товара
Нажмите кнопку **"Подробнее"** на карточке товара — откроется страница с полным описанием, ценой и изображением.

### Пагинация
На главной странице отображается не более 6 товаров. Для перехода между страницами используйте кнопки под списком товаров.
